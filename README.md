# Paradise Nursery

Paradise Nursery is a responsive houseplant shopping website built with React, React Router, Redux Toolkit, and CSS.

## Features
- Landing page with company name and Get Started button
- About Us page with company information
- Plant catalog with three categories and six plants per category
- Add-to-cart buttons that disable after adding an item
- Dynamic cart count in the navigation bar
- Shopping cart with quantity controls, item removal, item totals, and cart total
- Checkout message and Continue Shopping button

## Run locally
1. Install Node.js (LTS) from https://nodejs.org/
2. Open this folder in VS Code.
3. In the terminal, run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Technologies
- React
- Vite
- React Router
- Redux Toolkit
- React Redux
- CSS
